# Contributing

Thanks for your interest! This started as a hackathon project, but issues and PRs are welcome.

1. `make setup` (installs dev tools + pre-commit hooks)
2. Create a branch, make your change, add or adjust tests (`docs/08_TESTING.md`)
3. `make lint test`, and run `make reproduce` if results change
4. Use Conventional Commits (`feat:`, `fix:`, `docs:`, `test:`, `ci:`, `chore:`)
5. Open a PR using the template. CI must be green

Ground rules: public or synthetic data only, never commit tokens, and never claim quantum advantage without evidence.
